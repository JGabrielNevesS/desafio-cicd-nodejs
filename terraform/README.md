# Terraform — exemplos e instruções

Este diretório contém exemplos de configuração Terraform usados para fins de aprendizado e demonstração.

Arquivos principais

- `provider.tf` — configuração do provider
- `variables.tf` — variáveis esperadas pelo módulo
- `main.tf` — recursos de exemplo
- `output.tf` — outputs definidos


Pré-requisitos

- Terraform 0.12+ (ajuste conforme necessário)

Uso rápido

```bash
cd terraform
terraform init
terraform plan
terraform apply
# quando terminar (opcional)
terraform destroy
```
